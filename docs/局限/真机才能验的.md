# 局限:只有装到手机上才能验的几件事

记录日期:2026-10-11(学—做—记三条路都做完、准备出 APK 时)

背景:这台机器上只有命令行,没有模拟器、没有手机。凡是要**真设备**才成立的东西,
`flutter test` 里最多只能验到"逻辑对、接口调了",验不到"这件事真的发生了"。
下面按"能不能验"分开写。

## 已定量、原因已知的

### 实验册"存住了"只在临时目录里验过

- 现象:测试里用的是 `Hive.init(临时目录)` + 真开盒真写文件,
  关掉盒子再打开还能读回来 —— 这一层是**真验过的**
  (`app/test/journal_store_test.dart`,「关掉盒子再开,记录还在」)
- 没覆盖的是:真机上的目录从哪来。App 里走
  `getApplicationDocumentsDirectory()`,由 `path_provider` 在 Android 上给一个
  `/data/user/0/<包名>/app_flutter` 之类的路径
- 已定因:这条依赖平台通道,测试环境里根本没人应答,只能真机验
- 兜底写法:拿不到目录、或 `Hive.initFlutter()` 起不来,都不让 App 崩 ——
  退回 `MemoryJournalStore`(这次能用、关掉就没了),见 `app/lib/main.dart`

### 相机这条路,代码里只能走到"没拍成"

- 现象:测试里塞的是 `StubPhotoTaker`,能把"拍成了带照片"和"没拍成"两条分支都跑到,
  但**没有一次真的调用过系统相机**
- 已定因:`image_picker` 走的是平台通道 + 系统相机 App,测试环境里没有
- 已经补掉的一个真机坑:Android 11 起有"包可见性"过滤,`image_picker_android`
  是用 `queryIntentActivities` 找相机的,不在 manifest 的 `<queries>` 里声明
  `android.media.action.IMAGE_CAPTURE` 就会拿到空列表、拍照永远打不开。
  已加进 `app/android/app/src/main/AndroidManifest.xml`(出处:插件包内源码
  `ImagePickerDelegate.java:619`)。**加了没有实测过 —— 得真机点一次才知道对不对**

### 念不出声不会崩,但"念出来没有"没验

- 现象:`PhoneSpeaker` 优先放内容包里的 mp3(科学包 11 句用户听过确认可以,
  数学包 m01–m03 同款音色 2026-10-11 补齐),找不到音频文件时退回 `flutter_tts`
- 已定因:两个插件都走平台通道,测试里一律用 `FakeSpeaker`
- 没验的:真机上 `flutter_tts` 到底有没有中文语音包、语速 0.45 / 音调 1.15
  听着是不是给小孩的调子。**所有插件调用都包了 try/catch** ——
  念不出来不该让页面崩,这一点是照"宁可没声也别白屏"写的

### 练环节的口播是系统 TTS,和学环节的录音不是一个声音

- 现象:学环节三步放的是录好的 mp3(CosyVoice 龙呼呼童声);练环节一进去,
  题目、夸奖(「答对啦,你真棒!」)、提示(「再想一想,你可以的」)全走
  `flutter_tts` 系统语音 —— 同一个 App 里小龙的声音会变
- 出处:`app/lib/shell/practice_page.dart` 的 `_ask/_correct/_pick` 只给文字
  不给 clipKey,`PhoneSpeaker.say` 落到 TTS 分支
- 已定因(设计取舍,不是漏做):题目文字由模板参数拼出来(a、b 随题目变),
  没法逐句预录;夸奖虽是固定三句,但也跟着题面一起走 TTS 保持一致
- 界面上文字全都有,听不到只是少一层,不挡用
- 没验的:真机上这两段声音的落差听感如何;要是家长在意,后续可以把
  固定句(夸奖/提示)也录成 mp3,题面朗读仍只能 TTS

## 没验的(别当已知)

- **APK 装上去能不能起来**:`flutter build apk --release` 出了包 ≠ 装到手机上能用。
  字体(中文回退)、emoji 是不是彩色、`assets/content/` 能不能读到,
  全得装上才知道
- **刘海屏/小屏的排版**:截图固定 400×860。真机上 (刘海、状态栏高度、系统字体缩放)
  会不会把底下那排按钮顶出屏幕,没试
- **系统大字体会不会撑破布局**:小妍如果开了"字体放大",没说会不会溢出
- **照片存久了会不会被系统清理**:Android 的 `app_flutter` 目录一般不会被清,
  但各家 ROM 不一样。界面里已经按"文件可能没了"处理(画 🔍 占位,不报错)—— 
  **这是兜底,不是验证**
- ~~**音频文件是不是真的打进 APK 了**~~:2026-10-11 拆开 arm64 APK 数过 ——
  `assets/flutter_assets/assets/content/` 下 16 个文件全在(两包 topic.json +
  科学 11 句 + 数学 3 句)。**还剩真机能不能播没验**
