# 局限:从网上找美术素材

记录日期:2026-10-10(给龙呼呼找形象、"可以在网上找素材"那一轮)

背景:这台机器上没有模拟器也没有浏览器,能用的只有命令行和 WebFetch/WebSearch。
下面的结论都是这一轮实测撞出来的。

## 已定量、原因已知的

### WebFetch 打不开 Kenney(还有一个域名安全校验)

- 现象:`WebFetch https://kenney.nl/assets/animal-pack-redux` 直接被拒,
  报 "Unable to verify if domain kenney.nl is safe to fetch"
- 出处:2026-10-10,给龙呼呼找动物素材时
- 已定因:WebFetch 会先做域名安全校验,不在白名单的域名一律不发请求。
  **这是 WebFetch 这一层的限制,不是网络不通** —— 同一台机器上 `curl` 能连到
  kenney.nl(见下一条)
- 处理:WebFetch 拿不到就换 `curl`。但注意下一条:URL 猜不对会 404

### 猜 URL 一定出错

- 现象:`curl https://kenney.nl/assets/animal-pack-redux` 返回 HTTP 404
- 已定因:这条路径是猜的。Kenney 的素材页 URL 里带的是素材包自己的 slug,
  不是想当然的英文名。**想用这一站得先真拿到一个能打开的页面地址再下**,
  别顺着想象改 URL
- 现状:没再往下试

### WebSearch 给的是另一路风格,不是这个 App 要的

- 现象:搜"卡通动物素材 免费"这类词,回来的基本是两类 ——
  像素风 RPG 精灵图;或者 openclipart / publicdomainvectors 那种通用剪贴画
- 影响:跟动森风(平涂 + 粗描边 + 大圆角)差得很远,拿回来也贴不进界面
- 现状:不是通道问题,是**检索结果跟需求不匹配**。要在这类站点里淘到合口味的,
  得一家家翻,成本不低

### openclipart 的搜索接口在这台机器上连不通

- 现象:`curl "https://openclipart.org/search/json/?query=cute+snake&amount=12"`
  25 秒后超时,收到 0 字节
- 出处:2026-10-10
- 现状:**还没定因** —— 分不清是这一站本身慢/被墙,还是这台机器出去的通路问题。
  同一时段 `curl` 能连 kenney.nl,所以不像是完全没网

## 没验的(别当已知)

- **其它免版权素材站到底通不通**:Wikimedia Commons、publicdomainvectors 只在
  搜索结果里见过,一次都没实际下载验证过,别当成"能用"
- **同一个域名安全校验有没有白名单可走**:WebFetch 那层是不是有办法配置,
  没查过
- **下载下来的素材许可证到底是不是标称的那样**:这次一个文件都没下成,
  所以没有任何一份素材的许可证被实际核对过。以后真下到东西,
  许可证要一个个打开看原文,不能只看搜索结果的摘要
